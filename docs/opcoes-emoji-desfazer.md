# Opções de Emojis para o Botão "Desfazer Última Partida"

## Emoji Atual Implementado:
↩️ - Seta curva para esquerda (Desfazer)

## Outras Opções Sugeridas:

### Setas e Rotação:
- ⏪ - Seta dupla para trás (rebobinar)
- ◀️ - Seta para esquerda (voltar)
- 🔙 - Seta "BACK"
- 🔄 - Setas circulares (reload/refresh)
- ⤴️ - Seta curva para cima
- ↶ - Seta circular anti-horário
- ⟲ - Seta circular aberta

### Ações de Desfazer:
- ⬅️ - Seta simples para esquerda
- ⏮️ - Pular para trás
- 🔁 - Repetir/Reverter

### Símbolos de Atenção:
- ⚠️ - Atenção (uso com desfazer)
- 🚫 - Cancelar/Proibido

### Relacionados a Tempo:
- ⏱️ - Cronômetro
- ⏰ - Relógio despertador
- 🕰️ - Relógio antigo (voltar no tempo)

## Recomendação:
O emoji ↩️ é o mais intuitivo e universalmente reconhecido para "desfazer/voltar".
Alternativas fortes: ⏪ (rebobinar) ou 🔙 (back).
